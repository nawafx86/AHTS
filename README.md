# Asset Hardware Tracking System (AHTS)

A full-stack single-page application built to manage company hardware inventory (laptops, phones, tablets, desktops) and track device assignments across employees.

## Tech Stack
* **Backend:** ASP.NET Core (.NET Core RESTful Web API)
* **Database:** Microsoft SQL Server (Entity Framework Core)
* **Frontend:** Vanilla JavaScript (Fetch API), HTML5, CSS3 (served statically via `wwwroot`)

## Features
* **Live Inventory Metrics:** Tracks total assets, assigned hardware, and available stock in real time.
* **Asset Lifecycle Management:** Register new devices by serial number, categorize hardware types, and assign or unassign devices to employees.
* **Paginated Data Table:** Clean server/client pagination and dynamic status badges.
